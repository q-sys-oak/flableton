# FLABLETON Bridge downloads

The Bridge lets FLABLETON use the VST3 plugins installed on your computer, with their own windows.

| Your computer | Download |
| --- | --- |
| Windows 10/11 (64-bit) | [FLABLETON-Bridge.exe](FLABLETON-Bridge.exe) (or the [zip](FLABLETON-Bridge-Windows.zip)) |
| Mac (Apple Silicon or Intel, macOS 11+) | [FLABLETON-Bridge-Mac.zip](FLABLETON-Bridge-Mac.zip) |
| Linux (x86-64) | [FLABLETON-Bridge-Linux.tar.gz](FLABLETON-Bridge-Linux.tar.gz) |

Click the file name, then **Download raw file** (the ⤓ button).

1. Open the Bridge and leave its window open.
   - **Windows:** if "Windows protected your PC" appears, click **More info → Run anyway**.
   - **Mac:** unzip it, then right-click **FLABLETON Bridge → Open → Open**. You only need to do this the first time.
2. Open [FLABLETON](https://q-sys-oak.github.io/flableton/) in **Chrome or Edge** and press **Connect** under **VST**. If Chrome asks to let the site use apps on your device, choose **Allow**.
3. Click a plugin to add it, and use **🪟 Open plugin window** for its own controls.

These are early test builds and aren't code-signed yet, which is why Windows and Mac show warnings.
